# Smit Gadhavi — Portfolio

A responsive, header-free portfolio using plain HTML, CSS, and JavaScript. Static assets live in `dist/`. Serve that folder with any static HTTP server.

Personal content is in `dist/index.html`. Styling is in `dist/style.css`. Public GitHub latest-commit data is fetched in `dist/app.js` without credentials; the contribution calendar uses ghchart.rshah.org. Both have graceful fallback states. Project art is typographic editorial artwork, not application screenshots.

Only verified public repository details and user-provided personal details are included. No completion percentages are inferred from repository activity.
